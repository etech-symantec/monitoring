01도구 소개 및 구성

이 프로그램은 Windows 실행 파일 형태의 로컬 모니터링 도구이며, 내부적으로 Python/Flask 기반 웹 인터페이스를 포함합니다. ProxySG 장비의 다양한 상태 지표를 모아 보고 시계열 변화, 장비 간 비교, 주의·경고·위험 임계값을 관리합니다.

📡 다중 장비 상태 수집

등록한 장비를 정기적으로 조회하고, 전체 장비에 공통 폴링 간격을 적용합니다.

📈 분석·비교

24시간/15분, 1시간/1분 데이터 간격, 히스토리, 장비 비교 및 주요 지표 모아보기를 제공합니다.

🌐 프록시 경유 측정

별도 Ping 화면에서 프록시를 경유한 HTTP HEAD 요청의 왕복 시간을 측정합니다.

🛠 운영 자동화

이메일 임계값 알림, 자동 보존·삭제, 데이터 압축, DNS 설정을 제공합니다.

실행 파일 시작→로컬 웹 인터페이스 접속→ProxySG 장비 등록→정기 수집·조회→분석·알림·보관
프로그램 내부 리소스에서 확인한 기능을 설명합니다. 실행 파일을 Windows에서 직접 실행해 실장비와 통신하는 종단 간 검증은 수행하지 않았습니다.

02실행 및 접속

1
실행 파일 준비ProxySG-Dashboard_v1.6.exe를 Windows PC의 관리용 폴더에 보관합니다. 출처가 확인된 파일인지 내부 보안 절차에 따라 검사합니다.
2
프로그램 실행실행 파일을 시작합니다. Windows 방화벽이나 보안 제품의 연결 허용 메시지가 나오면 해당 프로세스·접속 범위를 확인합니다.
3
웹 화면 접근실행 시 안내되는 로컬 주소 또는 자동으로 열리는 브라우저에서 대시보드에 접근합니다. 고정 URL/포트는 이번 분석에서 확정되지 않았으므로 임의의 포트를 안내하지 않습니다.
4
정상 화면 확인상단에 데이터 간격, 장비 관리, 업로드, 히스토리, 모아보기, Ping, 설정 등의 조작 항목이 보이는지 확인합니다.
ProxySG 상태 모니터링 툴데이터 간격 · 장비 관리 · 히스토리 · Ping · 설정
24h / 15분1h / 1분📡 장비 관리📈 히스토리📌 모아보기🌐 Ping⚙ 설정

위 그림은 메뉴 구성의 이해를 위한 도식이며 실제 화면 캡처는 아닙니다.

실제 운영 전에는 프로그램을 종료하면 수집이 멈추는지, 재부팅 후 자동 시작되는지, 로컬 포트가 외부 NIC에 바인딩되는지를 별도로 점검하세요. 자동 시작·Windows 서비스 설치를 지원한다고 가정하지 않습니다.

03장비 등록 및 관리

3.1 단일 장비 등록

1
📡 장비 관리 클릭장비 관리 패널을 펼칩니다.
2
＋ 장비 등록 선택IP / Hostname, Username, Password를 입력합니다.
3
등록 후 목록 확인장비 목록과 대시보드의 새 장비 표시를 확인합니다. 연결 상태 및 수집 성공 여부를 살핍니다.
4
🔄 동기화 사용정기 수집을 기다리지 않고 현재 상태를 조회하려면 동기화를 실행합니다. 장비 편집 화면에는 활성화 스위치도 존재합니다.

3.2 여러 장비 일괄 등록

장비 관리의 펼치기 ▾ → 일괄 등록 영역에서 공통 계정(공통 Username, 공통 Password)과 파일 선택 필드를 이용할 수 있습니다. 등록 파일의 정확한 열 구성과 인코딩은 UI 리소스만으로 검증되지 않았으므로 화면 안내/실행 결과를 기준으로 작은 샘플부터 테스트하세요.

3.3 기존 장비 수정

장비 수정 화면에는 IP/호스트명, 계정, 비밀번호, 활성화 항목이 있으며 저장할 수 있습니다. 운영에서 제외할 장비는 삭제 전에 비활성화 방식으로 관리할지 먼저 검토합니다.

장비 자격 증명은 민감정보입니다. 공유 PC에서 실행하거나 프로그램 폴더·데이터 폴더를 다른 사람에게 전송하기 전에 저장 방식과 접근 권한을 확인하세요.

등록된 장비별 상태 카드에서 현재 수치와 추세를 확인합니다. 실무에서는 개별 수치뿐 아니라 최근 값, 평균 대비 편차, 동시간대 다른 장비와의 차이를 함께 판단하는 것이 중요합니다.

6.3 원인 분석 활용 예

장애 신고 시간을 기준으로 동일 구간의 CPU, 세션/TCP 관련 지표, 트래픽의 변화를 함께 보고 특정 장비만 변화했는지 전체 장비에서 공통 발생했는지 비교하세요. 단독 급등은 장비 편중 문제, 동시 급등은 공통 트래픽/외부 요인 등 여러 가능성을 조사하는 단서가 됩니다.

07🌐 Ping 실시간 모니터

이 화면의 Ping은 단순한 ICMP echo 테스트와 구분해야 합니다. 프로그램 화면 설명에 따르면 등록된 ProxySG 장비를 프록시로 경유하는 HTTP HEAD 요청을 대상으로 전송해 왕복 응답 시간을 측정합니다.

모니터링 PC→등록된 ProxySG→대상 웹 호스트→응답 시간 RTT
1
상단 🌐 Ping 열기Ping 화면에서 등록된 장비와 대상별 결과를 확인합니다.
2
＋ 대상 추가호스트 / IP와 선택적인 이름을 입력합니다.
3
결과 관찰화면에 따르면 10초마다 자동 갱신하며 측정 결과와 대상별 이력을 확인할 수 있습니다.
4
⏸ 전체 중지 / 전체 시작측정을 일시 중단·재개할 수 있습니다. 전체 중지 시에도 기존 대상·장비·이력은 유지된다고 화면에 명시되어 있습니다.
응답 시간이 짧아도 실제 웹 브라우징 체감 성능을 보장하지는 않습니다. 웹페이지 로딩에는 DNS, TLS, HTML, 스크립트 및 리소스 요청 등이 포함됩니다. 실제 체감 속도는 브라우저 개발자 도구의 Network 탭 등으로 별도 확인하세요.

08📂 sysinfo 파일 테스트 업로드

등록된 장비가 없어도 ProxySG sysinfo 텍스트 파일을 직접 업로드해 파싱 결과를 확인할 수 있는 테스트 기능입니다.

1
📂 업로드 메뉴 열기sysinfo 파일 업로드(테스트) 영역을 확인합니다.
2
파일 선택 또는 드래그 앤 드롭여러 파일을 동시에 선택할 수 있습니다.
3
파일로 파싱하기 클릭분석 결과가 화면에 표시되는지 확인하고 값이 원본과 일치하는지 표본 검증합니다.
sysinfo에는 호스트명, IP, 운영 설정 등 민감한 정보가 들어갈 수 있습니다. 테스트 전 개인정보·내부 주소·인증정보 포함 여부를 검토하고, 업로드 데이터가 어느 저장 위치에 남는지 확인하세요.

설정 순서

  1. SMTP 서버, 포트, TLS 사용 여부를 메일 관리자에게 확인합니다.
  2. SMTP 계정과 비밀번호를 입력하고 발신자 주소를 지정합니다.
  3. 수신 관리자 이메일을 등록하고 알림 기준/재발송 간격을 정합니다.
  4. 알림 설정 저장 후 테스트 메일 발송을 실행합니다.
  5. 실제 수신함과 스팸 격리함, 메일 서버 발송 기록을 확인합니다.
화면 안내에는 알림 검사 대상이 상단의 데이터 간격(24h/15분 또는 1h/1분) 선택에 연결된다고 설명되어 있습니다. 데이터 간격 변경 시 알림 확인 기준에 어떤 영향이 있는지 테스트 장비로 확인한 후 운영에 적용하세요.

11🌐 DNS / 호스트명

설정 → DNS / 호스트명은 TCP 서버 호스트명 확인에 관련된 기능입니다. 현재 DNS 방식, 수동 DNS 설정, PC/서버 기본 DNS 재조회(Fallback) 여부를 관리할 수 있습니다.

  1. 현재 DNS 방식을 확인합니다.
  2. 수동 DNS를 사용할 경우 내부 DNS 서버를 정확히 지정합니다.
  3. 수동 DNS에서 조회되지 않으면 PC/서버 기본 DNS로 다시 조회 옵션의 사용 여부를 결정합니다.
  4. 저장하고 적용 후 내부 주소와 외부 도메인에 대한 이름 확인 결과를 점검합니다.
  5. 설정 오류가 의심되면 수동 입력 모두 비우기 기능을 신중하게 사용합니다.
내부 IP를 외부 DNS로 조회하면 호스트명이 확인되지 않거나 운영 정보가 외부로 전달될 수 있습니다. 내부 DNS 사용 정책을 우선 적용하세요.

12🗄 저장 데이터 관리

정기 폴링으로 누적되는 시계열(snapshot/metrics) 데이터에 대한 정리·자동 보존·압축 기능이 있습니다. 화면 설명에는 데이터 정리 시 장비 등록 정보는 삭제되지 않는다고 명시되어 있습니다.

작업설정/실행 메뉴의미

자동 보존자동 삭제 사용 / 보존 일수 / 확인 주기 / 예약 설정 저장지정한 기간을 기준으로 오래된 데이터 정리

운영 주의: 기록 삭제 전 데이터 백업 여부, 보존 정책, 조사 중인 장애 기록의 필요성을 확인하세요. 즉시 실행 버튼은 실데이터에 영향을 줄 수 있으므로 테스트 환경에서 먼저 동작을 확인하는 것이 안전합니다.

13모아보기 지표 및 카드 표시 편집

📌 모아보기 지표

선택한 지표를 여러 장비 간 나란히 비교합니다. 체크/해제 시 즉시 저장된다고 화면에 설명되어 있으며 전체 해제 기능이 있습니다.

🗂 카드 표시

선택하지 않은 카드를 대시보드에서 완전히 숨김 처리하며 모든 장비에 공통 적용됩니다. 전체 다시 보이기 기능이 있습니다.

‘모아보기 지표 선택’은 비교 화면의 구성만 바꾸지만, ‘카드 표시’는 본 대시보드의 카드 자체를 숨깁니다. 지표가 사라졌다면 데이터를 잃었다고 판단하기 전에 카드 숨김 설정을 확인하세요.

15FAQ 및 운영 점검표

Q. 1분 폴링이면 1분 단위 데이터만 보이나요?
아닙니다. 폴링 주기는 도구의 장비 조회 빈도이며, 24h/15분 또는 1h/1분은 ProxySG 내부 통계 데이터의 표시 해상도입니다.
Q. 장비를 등록하지 않고 파일로 테스트할 수 있나요?
예. 업로드 메뉴에 sysinfo 텍스트 파일 파싱 테스트 기능이 있으며 여러 파일 선택도 가능합니다.
Q. Ping 기능은 Windows의 ping 명령과 같은가요?
아닙니다. 도구 설명에는 ProxySG 프록시 경유 HTTP HEAD 요청과 RTT 측정으로 표시되어 있습니다. ICMP 지연과 직접적으로 동일한 수치가 아닙니다.
Q. 이메일 알림은 누구에게 보내나요?
설정 화면에 관리자 이메일 최대 5개 입력란이 있고, SMTP 서버·인증을 설정한 뒤 테스트 발송할 수 있습니다.
Q. 데이터를 삭제하면 장비도 삭제되나요?
저장 데이터 관리 화면 설명에서는 시계열 기록 정리 시 장비 등록 정보 자체는 삭제되지 않는다고 명시되어 있습니다.
